# Global Olympic Sports Performance Analysis

## About the project

This project uses Olympic data to look at medals, sports, countries, regions, and host countries. I used Tableau to make charts and a dashboard that helps people understand the data.

## Datasets used

The project uses these four CSV files:

- `athletes.csv` — athlete details and medals.
- `medal_results.csv` — medal results, countries, regions, and investment categories.
- `games_summary.csv` — details and medal totals for Olympic editions.
- `alltime_country_rankings.csv` — all-time medal totals by country.

## Charts in the dashboard

The dashboard is planned to include these nine charts:

1. Average medals per athlete by sport.
2. All-time medals by country.
3. Medalist rate by sport.
4. Sports investment and medal performance by country (bubble chart).
5. Average medal efficiency by investment category.
6. Average medal efficiency by region.
7. Total medals over the years.
8. Host-country medal performance.
9. Share of all-time medals by region.

## Main steps

1. Collected the four CSV datasets.
2. Opened the data in Tableau.
3. Created the charts.
4. Put the charts into one dashboard.
5. Saved the Tableau workbook and published the dashboard to Tableau Public.

## Important note

The investment data uses categories such as Low, Medium, and High. It does not provide actual money spent, so this project does not calculate financial return on investment. Some medal-efficiency values are above 100, so those values should be checked before making strong conclusions.
